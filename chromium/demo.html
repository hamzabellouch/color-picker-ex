🎨 Color Picker Test Page

Use this page to test the Chromium Color Picker extension.

How to test:
  1. Click the Color Picker extension icon in your Chrome toolbar, or press Alt+Shift+C.
  2. Move your cursor over any color box or gradient below. Notice the floating badge with the color swatch and live HEX code.
  3. Left-click to pick the color. The Color Picker card appears!
  4. Click any format's copy icon to copy to clipboard.
  5. Click the ⚙️ settings button to toggle formats (HEX, RGB, HSL, HSV, CMYK, HSB).
